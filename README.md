# VidTop — bộ cài và kênh cập nhật

Repo này chỉ chứa bộ cài VidTop (Releases). Tool đã cài tự kiểm tra bản mới tại đây và mời khởi động lại để cập nhật.

- Tải bản mới nhất: https://github.com/ecomreview/vidtop-releases/releases/latest
- Mỗi bản gồm `VidTop-Setup-<phiên bản>.exe`, `.blockmap` và `latest.yml` (electron-updater).
